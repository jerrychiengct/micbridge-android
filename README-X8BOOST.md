# X8 Boost 0.1 test

A no-root HONOR X8b-oriented PUBG Mobile launch helper.

## Test features
- Live battery temperature, RAM, thermal status and max display mode.
- Optional Android WRITE_SETTINGS access for brightness and refresh-rate preference.
- Optional Do Not Disturb policy access.
- One-tap optimisation + PUBG Mobile launch.
- Backup/restore of changed phone settings when returning to X8 Boost.
- Direct PUBG app-settings shortcut.

## Deliberately not included
- No CPU/GPU overclocking.
- No thermal-protection bypass.
- No PUBG config/OBB editing.
- No device spoofing or hidden-FPS unlocks.
- No anti-cheat bypass.

This is a personal test build, not a claim of guaranteed FPS improvement. OEM firmware may ignore refresh-rate system keys.

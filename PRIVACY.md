# Privacy

MicBridge 0.4.1 processes microphone audio locally for live output. It does not create microphone recordings, send audio to a server, include advertising or analytics, or request internet access. Effect settings and gain preferences are stored locally on the phone. Noise calibration measures a background level for the current session; it does not save an audio file.

Android microphone permission is used for capture. Nearby devices permission on Android 12+ is used to access connected Bluetooth audio-device information. Bluetooth pairing is performed in Android settings.

GitHub / manufacturer / Ko-fi links and email buttons open another app. The external app or service's own privacy practices apply. Ko-fi handles any support payment externally; MicBridge receives no payment details. Leaving MicBridge stops the live session. Donation / collaboration email buttons open a draft for the user to send; MicBridge sends no email automatically.
